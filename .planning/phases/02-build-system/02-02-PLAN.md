  <action>
    Create `scripts/build.mjs` — the zero-dependency build script. This replaces `npm run build` (Vite), so no Vite dependency is needed in the output (per D-07). It MUST:
    - Import only: `import { readFileSync, writeFileSync, mkdirSync, cpSync, existsSync } from 'fs'`, `import { resolve, dirname } from 'path'`, `import { fileURLToPath } from 'url'`
    - Read the `BASE_PATH` env var (default to `''` for local preview)
    - Be ≤200 lines total
    - Read CSS/JS files from `src/styles/` and inject into `<style>`/`<script>` blocks (per D-06)

    **Build pipeline (in order):**

    1. **Read BASE_PATH** from `process.env.BASE_PATH || ''`
    2. **Scaffold output directories** (D-18):
       ```js
       const dirs = ['dist', 'dist/locales', 'dist/fonts', 'dist/images'];
       dirs.forEach(d => { if (!existsSync(d)) mkdirSync(d, { recursive: true }); });
       ```

    3. **Define the marker replacement function:**
       ```js
       function assemble(templatePath) {
         let html = readFileSync(templatePath, 'utf-8');
         html = html.replace(/<!--#include\s+(.+?)-->/g, (_, path) => {
           return readFileSync(path.trim(), 'utf-8');
         });
         return html;
       }
       ```

    4. **Read CSS files** and prepare inline `<style>` blocks:
       ```js
       const cssFiles = [
         { id: 'wk-tokens', path: 'src/styles/wolknitive-tokens.css' },
         { id: 'wk-base', path: 'src/styles/wolknitive-base.css' },
         { id: 'wk-animations', path: 'src/styles/wolknitive-animations.css' },
       ];
       const styleBlocks = cssFiles.map(f => {
         const css = readFileSync(f.path, 'utf-8');
         return `<style id="${f.id}">\n${css}\n</style>`;
       });
       ```

    5. **Rewrite asset paths** with BASE_PATH prefix:
       ```js
       function rewritePaths(html) {
         if (!basePath) return html;
         // Replace /fonts/ paths
         html = html.replace(/(href|src)=["']\/fonts\//g, `$1="${basePath}fonts/`);
         // Replace /images/ paths
         html = html.replace(/(src|srcset)=["']\/images\//g, `$1="${basePath}images/`);
         return html;
       }
       ```

    6. **Build index.html:**
       ```js
       let indexHtml = assemble('src/html/index.html');
       // Inject CSS into <style id="wk-tokens">, <style id="wk-base">, <style id="wk-animations">
       styleBlocks.forEach((block, i) => {
         const id = cssFiles[i].id;
         indexHtml = indexHtml.replace(
           new RegExp(`<style id="${id}">\\s*<!-- injected by build script -->\\s*</style>`),
           block
         );
       });
       indexHtml = rewritePaths(indexHtml);
       writeFileSync('dist/index.html', indexHtml, 'utf-8');
       ```

    7. **Build 404.html** (same process):
       ```js
       let notFoundHtml = assemble('src/html/404.html');
       // Same CSS injection as index.html
       styleBlocks.forEach((block, i) => {
         const id = cssFiles[i].id;
         notFoundHtml = notFoundHtml.replace(
           new RegExp(`<style id="${id}">\\s*<!-- injected by build script -->\\s*</style>`),
           block
         );
       });
       notFoundHtml = rewritePaths(notFoundHtml);
       writeFileSync('dist/404.html', notFoundHtml, 'utf-8');
       ```

    8. **Copy i18next vendor JS** (D-19):
       ```js
       if (existsSync('node_modules/i18next/dist/umd/i18next.min.js')) {
         cpSync('node_modules/i18next/dist/umd/i18next.min.js', 'dist/locales/i18next.min.js');
       }
       if (existsSync('node_modules/i18next-browser-languagedetector/dist/umd/i18nextBrowserLanguageDetector.min.js')) {
         cpSync('node_modules/i18next-browser-languagedetector/dist/umd/i18nextBrowserLanguageDetector.min.js', 'dist/locales/i18nextBrowserLanguageDetector.min.js');
       }
       ```

    9. **Copy locale JSON files** (D-13):
       ```js
       ['en', 'es', 'de'].forEach(locale => {
         const src = `src/i18n/locales/${locale}.json`;
         if (existsSync(src)) {
           cpSync(src, `dist/locales/${locale}.json`);
         }
       });
       ```

    10. **Log completion:**
        ```js
        console.log('✓ Build complete: dist/index.html, dist/404.html');
        console.log('✓ Assets: locales/, fonts/ (empty), images/ (empty)');
        ```

    **NOTES:**
    - The `<!-- injected by build script -->` comment in `_head.html` is the placeholder text that the build script replaces with actual CSS content. Make sure the regex replacement in step 6 matches whatever placeholder text Plan 01's `_head.html` uses. If Plan 01 uses `/* injected by build script */` instead, adjust the regex accordingly.
    - The CSS injection pattern must match the exact format of `<style id="wk-tokens">...</style>` in _head.html. The build script reads the style ID, finds the matching tag in the assembled HTML, and replaces its content.
    - Error handling: if a partial file is missing, `readFileSync` will throw. That's acceptable for a build script — fail fast.
    - No TypeScript, no JSX, no transpilation needed. This is plain ESM JavaScript.
