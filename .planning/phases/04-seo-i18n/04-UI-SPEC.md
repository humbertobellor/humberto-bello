## Interaction Contract — Language Switcher

### Structure Change

**Before** (current `_nav.html`):
```html
<button class="wk-nav-link" data-i18n-switch="en" data-active="true">EN</button>
<button class="wk-nav-link" data-i18n-switch="es">ES</button>
<button class="wk-nav-link" data-i18n-switch="de">DE</button>
```

**After** (Phase 4):
```html
<a href="/dossier/" class="wk-nav-link" data-active="true">EN</a>
<a href="/dossier/es/" class="wk-nav-link">ES</a>
<a href="/dossier/de/" class="wk-nav-link">DE</a>
```

- Paths use `BASE_PATH` prefix (e.g., `/dossier/` for English default)
- Active locale detection is passive — the active state is baked into each locale HTML file at build time, not set by JS at runtime
- Each locale page hardcodes its own `data-active` on the correct link

### Active State

The `data-active` attribute on the current locale link triggers the existing CSS rule (from `wolknitive-base.css` or `_nav.html` styling). No new CSS needed — the existing `.wk-nav-link[data-active]` styling applies.

### Behavior

- **Click behavior**: Standard `<a href>` — full page navigation to locale HTML file
- **No JS required** for switching — pure HTML navigation
- **Progressive enhancement**: Site works without any JS; language switcher is pure `<a>` links

## Interaction Contract — Locale Redirect Script

### Location

Inline `<script>` in `<head>`, after the IntersectionObserver script.

### Behavior

```javascript
(function() {
  var locale = localStorage.getItem('wk-locale');
  if (!locale || locale === 'en') return; // English is default, no redirect needed
  var path = window.location.pathname;
  if (path.indexOf('/' + locale + '/') !== -1) return; // Already on correct locale
  if (path.indexOf('/dossier/') === -1) return; // Not on dossier path
  window.location.replace('/dossier/' + locale + '/');
})();
```

### Contract

- **~5 lines** of vanilla JS, no dependencies
- **Reads** `localStorage.getItem('wk-locale')` — key name: `wk-locale`
- **Redirects** to locale subdirectory if not already there
- **Guard against redirect loops**: checks if already on correct locale path
- **Guard against non-dossier paths**: only redirects within `/dossier/`
- **Uses `window.location.replace()`** — no history entry for the redirect

### Language Switcher Click Handler

On click of a language switcher `<a>` link, save locale to localStorage before navigation:

```javascript
document.querySelectorAll('.wk-nav-link[data-active]').forEach(function(link) {
  link.addEventListener('click', function() {
    var text = this.textContent.trim().toLowerCase();
    if (text === 'en' || text === 'es' || text === 'de') {
      localStorage.setItem('wk-locale', text);
    }
  });
});
```

- **Attached** to the language switcher links in the existing IntersectionObserver script block
- **Saves** `localStorage.setItem('wk-locale', locale)` before navigation
- **No i18next needed** — localStorage is the persistence mechanism

## Interaction Contract — Per-Locale HTML Generation

### Build Output Structure

```
dist/
├── index.html          (English — default locale)
├── 404.html            (English)
├── es/
│   └── index.html      (Spanish)
├── de/
│   └── index.html      (German)
├── sitemap.xml         (generated, all 3 locales)
├── robots.txt          (copied/updated)
├── fonts/              (from Phase 3)
├── images/             (from Phase 3)
└── .nojekyll           (from Phase 5)
```

### data-i18n Attributes

Section content elements use `data-i18n="key"` attributes. Build script reads locale JSON and replaces `textContent` at build time.

```html
<!-- Before build -->
<h1 data-i18n="hero.title">Default content here</h1>
<span data-i18n="nav.about">About</span>

<!-- After build (en locale) -->
<h1>Software Engineering | Architecture | Hyperscalers | Applied AI | Solopreneur</h1>
<span>About</span>
```

- **Simple text nodes**: `data-i18n="hero.badge"`, `data-i18n="nav.about"`, etc.
- **Array items** (e.g., `hero.bullets[0]`): Use `data-i18n="hero.bullets" data-index="0"` pattern
- **Nested objects** (e.g., `skills.categories.ai.title`): Use dot notation `data-i18n="skills.categories.ai.title"`

### Build Script Order of Operations

1. Read locale JSON files (`en.json`, `es.json`, `de.json`)
2. Assemble base HTML from partials (existing `assemble()` function)
3. For each locale:
   a. Copy base HTML
   b. Replace `data-i18n` attributes with locale content
   c. Inject locale-specific `<title>`, `<meta>` from `seo.*` keys
   d. Set `<html lang="xx">`
   e. Set `data-active` on correct language switcher link
   f. Rewrite asset paths with `BASE_PATH`
   g. Inject CSS style blocks
   h. Write to `dist/{locale}/index.html` (or `dist/index.html` for English)
4. Generate `sitemap.xml`
5. Copy `robots.txt`
