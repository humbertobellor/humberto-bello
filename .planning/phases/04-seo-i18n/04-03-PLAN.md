**Fix the replaceI18n function in scripts/build.mjs to:**

1. **For `<meta>` tags**: Replace the `content="..."` attribute value instead of injecting text content. The current function replaces `data-i18n="seo.description"` with `>value<` which breaks the `<meta>` tag and leaves the original `content="ENGLISH"` untouched.

   Fix: Add a meta tag handler that runs BEFORE the text content handler:
   ```javascript
   // Handle <meta> tags: replace content attribute value
   html = html.replace(
     /(<meta[^>]*?)content="([^"]*)"([^>]*?)data-i18n="([^"]+)"/g,
     (_, pre, _oldContent, mid, key) => {
       const value = resolveKey(data, key);
       if (typeof value === 'string') {
         return `${pre}content="${value}"${mid}`;
       }
       return `${pre}content="${_oldContent}"${mid}data-i18n="${key}"`;
     }
   );
   // Also handle <meta ... data-i18n="..." ... content="...">
   html = html.replace(
     /(<meta[^>]*?)data-i18n="([^"]+)"([^>]*?)content="([^"]*)"/g,
     (_, pre, key, mid, _oldContent) => {
       const value = resolveKey(data, key);
       if (typeof value === 'string') {
         return `${pre}${mid}content="${value}"`;
       }
       return `${pre}data-i18n="${key}"${mid}content="${_oldContent}"`;
     }
   );
   ```

2. **For `<title>` tags**: Replace text content properly. Current regex matches `data-i18n="key">` and replaces with `>value<` but leaves original text.

   Fix: Use a regex that matches the full text node:
   ```javascript
   // Handle <title> and text elements: replace data-i18n attribute AND original text content
   html = html.replace(
     /(data-i18n="([^"]+)"[^>]*>)([^<]*)/g,
     (_, _match, key, _originalText) => {
       const value = resolveKey(data, key);
       if (typeof value === 'string') return `>${value}<`;
       return `data-i18n="${key}"` + _originalText;  // fallback: keep original
     }
   );
   ```

3. **Also handle `<title>` tags which have `data-i18n`**: The `<title>` tag currently has `data-i18n="seo.title"` — the text content replacement should work for it after the meta handler runs.

4. **Add a helper function `resolveKey(data, key)`** that extracts value from locale JSON using dot-notation and array indexing:
   ```javascript
   function resolveKey(data, key) {
     const parts = key.split('.');
     let value = data;
     for (const part of parts) {
       const arrMatch = part.match(/^(\w+)\[(\d+)\]$/);
       if (arrMatch) {
         value = value[arrMatch[1]];
         if (value) value = value[parseInt(arrMatch[2])];
       } else {
         value = value ? value[part] : undefined;
       }
     }
     return value;
   }
   ```

5. **Move sitemap generation inside the try/catch block** (currently outside at lines 163-191).

   // Copy opengraph.jpg for social sharing
